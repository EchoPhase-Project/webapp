# Sesiuni

Fiecare dispozitiv autentificat în contul dvs. este o sesiune: de unde și când s-a autentificat și când a fost folosit ultima dată.

- **Revocați** o sesiune pe care nu o recunoașteți: acel dispozitiv este deconectat.
- Dacă credeți că altcineva vă știe parola, schimbați-o în profil: toate celelalte dispozitive sunt deconectate.
