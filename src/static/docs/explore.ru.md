# Обзор

В Обзоре собраны пакеты, которые другие опубликовали как публичные; сначала самые устанавливаемые. Откройте пакет, чтобы прочитать README, посмотреть workflow последней версии, нужные им подключения и версии.

## Поиск

Одна строка поиска, как на GitHub: слова ищут по названиям и описаниям, а `tag:имя` оставляет пакеты с этим тегом (`tag:discord-bot guilds`). Клик по тегу на карточке добавляет его в строку.

## Установка

**Установить** создаёт ваш пакет из версии: его workflow выключены и с теми же ключами, поэтому вызывают друг друга как раньше. Для каждого подключения, которое они используют, выберите своё (сначала выбрано подключение с тем же именем) или оставьте на потом. Webhook'и получают новые секреты.

Пакет автора остаётся у него: вы меняете свою копию. Пакеты, которыми с вами поделились, и пакеты по ссылке устанавливаются так же.
