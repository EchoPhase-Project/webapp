# Notițe

Notițele se scriu în Markdown: ale dvs., cele partajate cu dvs. și cele scrise de workflow-urile dvs. (blocurile de notițe).

## Partajare

Partajați o notiță cu cineva după numele de utilizator, pentru citire sau pentru editare împreună. Cel cu care ați partajat-o o poate părăsi; dvs. puteți opri partajarea oricând.

## Editare împreună

O notiță ține minte versiunea la care a fost deschisă. Salvarea peste o versiune mai nouă (altcineva a salvat între timp) este refuzată, ca să nu se piardă nicio modificare: deschideți-o din nou, apoi salvați.
