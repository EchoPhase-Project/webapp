# Notes

Notes are written in Markdown: yours, those shared with you, and those your workflows write (the note blocks).

## Sharing

Share a note with someone by their username, to read it or to edit it together. Someone you shared a note with can leave it; you can stop sharing at any time.

## Editing together

A note remembers the version it was opened at. Saving over a newer version (someone else saved meanwhile) is refused, so nobody's change is lost: open it again, then save.
