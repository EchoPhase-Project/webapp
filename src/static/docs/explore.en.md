# Explore

Explore lists the packages others published as public, most installed first. Open one to read its README, the workflows of its latest version, the connections they use and its versions.

## Searching

One search line, as on GitHub: words search names and summaries, and `tag:name` keeps the packages with that tag (`tag:discord-bot guilds`). Picking a tag on a card puts it into the line.

## Installing

**Install** makes a package of yours from a version: its workflows, turned off, with the same keys, so they call each other as they did. For each connection the workflows use, pick one of yours (one with the same name is picked to start with) or leave it for later. Webhooks get new secrets.

The author's package stays theirs: what you change is your copy. Packages shared with you, and unlisted ones you have the link to, install the same way.
