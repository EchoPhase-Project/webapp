# Заметки

Заметки пишутся в Markdown: ваши, те, которыми с вами поделились, и те, что пишут ваши workflow (блоки заметок).

## Доступ

Поделитесь заметкой с человеком по имени пользователя: для чтения или для совместной правки. Тот, с кем вы поделились, может отказаться от заметки; вы можете закрыть доступ в любой момент.

## Совместная правка

Заметка помнит версию, с которой её открыли. Сохранение поверх более новой версии (кто-то успел сохранить) не пройдёт, чтобы ничьи изменения не потерялись: откройте заметку заново и сохраните.
